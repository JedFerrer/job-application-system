# Plan Feature

Create a read-only plan after repository research. Follow the shared contract
in `AGENTS.md` and `docs/development-workflow.md`.

Include the objective, assumptions and unknowns, approved scope, explicit
exclusions, expected files, implementation approach, phased acceptance
criteria, focused and broader validation commands, Browser QA requirements,
risks, rollback notes, hard stop conditions, and a suggested commit message.

Do not edit files, run mutating setup, or begin implementation. Stop after the
plan and await one explicit implementation approval.
